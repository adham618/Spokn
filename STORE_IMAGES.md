## Tips for generation

- **Ideogram** works best for text-in-image (it renders readable UI text accurately)
- **Recraft** works best for clean UI mockups and vector-style artwork
- **DALL-E** works for conceptual tiles but may struggle with exact UI details
- For screenshots (4–8): generate a base image then manually composite your real UI on top using Figma, Canva, or even macOS Preview
- Alternatively, take real screenshots from Chrome with the extension loaded and crop/resize to 1280×800
